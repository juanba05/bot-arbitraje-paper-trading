# Reglas del proyecto

- Nunca abrir, leer, imprimir ni modificar .env.
- Nunca mostrar secretos, tokens, claves ni credenciales.
- Leer primero el archivo de progreso/planificación antes de proponer cambios.
- Antes de editar, explicar el plan y listar archivos a tocar.
- No hacer commits ni instalar dependencias sin pedir aprobación.
- Priorizar cambios pequeños, reversibles y bien explicados.
